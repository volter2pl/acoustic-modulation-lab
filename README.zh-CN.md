**声学调制实验室让普通浏览器中的 AM 和 FM 广播原理变得可见、可听。**

实验室并不调制电磁载波，而是调制一个以 48 kHz 采样率音频波形保存的
声学载波。物理介质虽然不同，但 AM 和 FM 的方程，以及边带、调谐和解调
原理完全相同。

· [日本語](https://volter2pl.github.io/acoustic-modulation-lab/?lang=ja)

```text
语音或音乐
    ↓
AM 或 FM 发射器
    ↓
高频声学波形
    ↓
已调谐的 AM 或 FM 接收器
    ↓
恢复的语音或音乐
```

## 实验室展示什么

选择一种调制方式，比较它们如何承载同一段录音：

| | AM | FM |
| --- | --- | --- |
| 发生变化的量 | 载波幅度 | 瞬时频率 |
| 主要控制参数 | 调制度 | 频偏 |
| 频谱 | 载波和两个边带 | 载波和多个边带 |
| 接收器测量量 | I/Q 包络幅值 | I/Q 相位变化 |
| 附加实验 | 过调制 | 缩放 RDS |

应用程序依次展示三个信号：

1. **消息** — 内置录音、你自己的音频文件或麦克风输入。
2. **已调制信号** — AM 或 FM 载波及其边带。
3. **恢复的音频** — 相应接收器重建出的消息。

所有可视化都是频谱图：时间从左向右推进，频率从下向上升高，颜色越亮
表示能量越强。消息和恢复音频的视图覆盖 0–8 kHz；已调制信号的视图覆盖
48 kHz 采样率所允许的完整 0–24 kHz 范围。

完整理论和实现说明请参阅：

- [幅度调制](docs/zh-CN/am.md)
- [频率调制与 RDS](docs/zh-CN/fm.md)

## 单个电台与广播频带

**单个电台**模式提供所选调制方式的特征参数。AM 的调制度可在 0% 到
150% 之间调整，包括有意设置的过调制。FM 可以调整载波频偏，并可选用
缩放后的 PS 或 RadioText 数据。

**广播频带**模式将三个独立电台组合到一个音频文件中，载波默认位于 5、12
和 19 kHz。每个电台都有各自的节目、信号电平、4 至 20 kHz（步进 0.1 kHz）
的载波频率，以及接收点 0° 至 345°（步进 15°）的相位。共享频带持续播放时，
接收器仍可连续调谐，因此移动调谐滑块会实时切换电台。

载波可以彼此靠近，也可以设为相同频率。重叠信道会产生干扰，无法仅靠调谐
分离。对于相同的同频信号，相对相位决定波形是相互增强还是相互抵消。

恢复的频谱图和可下载的 WAV 是在最后一次分析频率处生成的快照。实时音频
会立即跟随调谐滑块；如果频谱对应的是旧频率，界面会加以标记，直到使用
**更新频谱和 WAV**。

各节目不必具有相同的时长。共享信道以最长的录音为准；较短的 AM 或 FM
节目结束后，其发射器会以未调制载波的形式继续工作。

## 为什么这是一个类比模型

广播载波以无线电频率的电磁波形式传播。本实验使用空气压力变化和音频
频率，使普通浏览器能够生成、显示并在某些情况下播放这些信号。

| 无线电传输 | 声学实验室 |
| --- | --- |
| 电磁载波 | 声压载波 |
| 射频振荡器 | 浏览器生成的振荡器 |
| 天线和自由空间 | 音频文件，或扬声器与空气 |
| 无线电接收器 | 浏览器中的 AM 或 FM 解调器 |

这并不是把无线电波转换成声音，而是把同一套调制数学应用到另一种波上。

## 尝试实验

可以使用内置示例、拖放音频文件或录制自己的声音。浏览器通常支持 WAV、
MP3、M4A/AAC、OGG/Vorbis 和 WebM/Opus，但具体情况会因浏览器而异。输入
时长限制为 120 秒。

生成的高频信号会以较低音量播放，并且绝不会自动开始。设备的扬声器、
麦克风、音效增强和滤波器可能会滤除接近可听频谱上限的载波。

在任意空闲端口上本地运行实验室：

```bash
npm start -- 8080
```

然后打开 `http://localhost:8080`。

AM 和 FM 改变的是信息的表示方式；它们不会加密、压缩或隐藏原始录音。
