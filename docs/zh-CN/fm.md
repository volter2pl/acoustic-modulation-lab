频率调制把消息保存在恒幅载波的瞬时频率中。与 AM 不同，载波包络不会
直接跟随节目变化。

## FM 如何保存消息

设 `m(t)` 是归一化消息，`fc` 是载波频率，`Δf` 是最大频偏：

```text
fi(t) = fc + Δf · m(t)
```

对于 18 kHz 载波和 ±1 kHz 频偏：

```text
m(t) = -1.0  →  fi(t) = 17 kHz
m(t) =  0.0  →  fi(t) = 18 kHz
m(t) = +1.0  →  fi(t) = 19 kHz
```

频率是相位的导数，因此正确的离散 FM 必须持续累加振荡器相位：

```text
phase += 2π · instantaneousFrequency / sampleRate
fmSample = sin(phase)
```

如果根据频率和绝对时间各自重新计算独立的正弦值，就会产生相位不连续，
无法得到正确的 FM。

## FM 接收器如何工作

接收器把信号与所选载波频率上的正弦和余弦振荡器混频。滤波后的分量组成
复基带信号：

```text
z[n] = I[n] + jQ[n]
```

接收器测量相邻采样之间的相位变化：

```text
Δφ[n] = arg(z[n] · conjugate(z[n-1]))
m[n] ≈ Δφ[n] · sampleRate / (2π · Δf)
```

这种 I/Q 鉴频器无需单独的相位展开步骤就能恢复频偏。节目低通滤波器最终
留下原始录音。

## FM 带宽

瞬时频率范围只是载波频率加减频偏。但 FM 信号还包含边带，因此实验采用
卡森公式的实用估算：

```text
FM 占用带宽 ≈ 2 ·（频偏 + 消息带宽）
```

单个电台的音频被限制在 2.4 kHz 语音频带内。如果某组载波频率和频偏会
使估算边带越过频谱下边界或 24 kHz 奈奎斯特极限，界面就会拒绝该组合。

## 缩放 RDS

RDS 展示了节目音频与数字信息如何同时调制同一个 FM 载波。在真实的立体声
FM 复合基带中，RDS 使用 57 kHz 抑制载波，这正好是 19 kHz 立体声导频的
三倍，数据速率为 1187.5 bit/s。

48 kHz 音频文件无法表示 57 kHz，因此模型把所有 RDS 时钟频率除以八，
同时保持它们之间的比例关系：

| 分量 | 广播 RDS | 声学模型 |
| --- | ---: | ---: |
| 导频 | 19 kHz | 2.375 kHz |
| RDS 副载波 | 57 kHz | 7.125 kHz |
| 数据速率 | 1187.5 bit/s | 148.4375 bit/s |

可用模式包括：

- **无** — 仅节目音频；
- **PS** — 0A 组中最多八个字符的节目服务名称；
- **RadioText** — 2A 组中最多 64 个字符的文本。

本教学实现中的 RDS 文本字段使用可打印的单字节拉丁字符，因此不能直接
发送汉字。简体中文界面的默认 RadioText 使用拉丁字母转写；这忠实反映了
当前数据块编码的限制，而不是把汉字伪装成可传输内容。

模型会生成 RDS 数据块、校验字、差分编码和双相符号。接收器从已解调波形
中恢复有效数据组；文本并不存储在 WAV 元数据中。如果音源太短，无法完成
一个完整的数据周期，系统会用静音节目延长传输。

解调后，完整复合基带进入数据解码器。另一条独立的监听路径会移除缩放导频，
并应用陡峭的节目低通滤波器，因此恢复音频播放器中是节目音频，而不是
RDS 音调。

RDS 需要宽得多的基带，因此会缩小安全的声学载波范围。这是经过缩放的教学
波形，商用 RDS 接收器无法解码它。

## 多个 FM 电台

广播频带模式组合位于 5、12 和 19 kHz 的载波。每个电台使用 ±0.75 kHz
频偏和 2 kHz 节目频带：

```text
5 kHz FM  ─┐
12 kHz FM ─┼─→ 一个声学广播频带
19 kHz FM ─┘
```

估算信道宽度约为 5.5 kHz，相邻电台之间仍有间隔。共享频带持续播放时，
实时接收器会连续改变本地振荡器，因此调谐效果就像转动收音机旋钮。

广播频带模式会关闭 RDS。在 1:8 模型中，一个 RDS 电台大约占用 17.2 kHz；
可用的 0–24 kHz 音频频谱无法容纳多个如实建模的 RDS 信道。

节目结束后，其消息变为零，电台则继续发送未调制载波。信号电平控件会改变
各电台强度，混音器则为三个发射器共同保留余量。

## 观察要点

- 较低的载波更容易被听成不断变化的哨声。
- 频偏越大，能量分布得离载波越远。
- 载波幅度保持恒定，变化的是振荡速率。
- 在 FM 调制之前，RDS 会产生可见的高频复合基带分量。
- 调谐到电台之间时，接收器会抑制基带滤波器范围以外的载波。

FM 并不是隐藏在音调之下的原始音频副本。它是一条连续波形，其累积相位
承载着录音信息。
