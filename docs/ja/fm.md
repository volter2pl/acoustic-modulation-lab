周波数変調は、振幅が一定の搬送波の瞬時周波数にメッセージを保存します。
AM とは異なり、搬送波の包絡線が番組に直接追従することはありません。

## FM がメッセージを保存する仕組み

`m(t)` を正規化したメッセージ、`fc` を搬送周波数、`Δf` を最大周波数
偏移とします。

```text
fi(t) = fc + Δf · m(t)
```

18 kHz の搬送波と ±1 kHz の周波数偏移では、次のようになります。

```text
m(t) = -1.0  →  fi(t) = 17 kHz
m(t) =  0.0  →  fi(t) = 18 kHz
m(t) = +1.0  →  fi(t) = 19 kHz
```

周波数は位相の時間微分なので、正しい離散 FM は発振器の位相を連続的に
累積します。

```text
phase += 2π · instantaneousFrequency / sampleRate
fmSample = sin(phase)
```

周波数と絶対時間から毎回独立した正弦値を計算すると位相が不連続になり、
正しい FM 信号にはなりません。

## FM 受信機の仕組み

受信機は信号を、選択した搬送周波数の正弦・余弦発振器とミキシングします。
フィルター処理後の成分は、複素ベースバンド信号を形成します。

```text
z[n] = I[n] + jQ[n]
```

受信機は隣接するサンプル間の位相変化を測定します。

```text
Δφ[n] = arg(z[n] · conjugate(z[n-1]))
m[n] ≈ Δφ[n] · sampleRate / (2π · Δf)
```

この I/Q 周波数弁別器は、個別の位相アンラップ処理を行わずに周波数偏移を
復元します。番組用ローパスフィルターによって元の録音だけが残ります。

## FM の帯域幅

瞬時周波数範囲は搬送周波数に周波数偏移を加減した範囲だけです。しかし
FM 信号には側波帯もあるため、この実験ではカーソンの実用的な近似式を
使います。

```text
FM 占有帯域幅 ≈ 2 ·（周波数偏移 + メッセージ帯域幅）
```

単一局の音声は 2.4 kHz の音声帯域に制限されます。推定側波帯がスペクトル
下限または 24 kHz のナイキスト限界を越える搬送周波数と偏移の組み合わせ
は、インターフェースによって拒否されます。

## スケール変換した RDS

RDS は、番組音声とデジタル情報が同じ FM 搬送波を同時に変調できることを
示します。実際の FM ステレオ多重信号では、RDS は 19 kHz ステレオ
パイロットのちょうど 3 倍にあたる、抑圧された 57 kHz 副搬送波を使い、
データレートは 1187.5 bit/s です。

48 kHz 音声ファイルでは 57 kHz を表現できないため、すべての RDS
クロックを 8 分の 1 にし、相互関係を維持します。

| 成分 | 放送 RDS | 音響モデル |
| --- | ---: | ---: |
| パイロット | 19 kHz | 2.375 kHz |
| RDS 副搬送波 | 57 kHz | 7.125 kHz |
| データレート | 1187.5 bit/s | 148.4375 bit/s |

利用できるモードは次のとおりです。

- **なし** — 番組音声のみ。
- **PS** — 0A グループで送る 8 文字の Programme Service 局名。
- **RadioText** — 2A グループで送る最大 64 文字のテキスト。

PS と RadioText の入力には印字可能な ASCII 文字を使用します。未対応の
文字列は暗黙に置換せず、エンコード前に通知します。

この教育用実装の RDS テキスト欄は、印刷可能な 1 バイトのラテン文字を
使用するため、かなや漢字を直接送信できません。日本語インターフェースの
既定 RadioText はラテン文字のローマ字表記です。これは現在のデータブロック
符号化の制約を正直に示すためのものです。

モデルは RDS ブロック、チェックワード、差分符号化、バイフェーズ記号を
生成します。受信機は復調波形から有効なグループを復元します。テキストは
WAV メタデータとして保存されません。音源が完全なデータ周期より短い場合、
無音の番組音声で送信時間を延長します。

復調後、完全な多重信号がデータデコーダーに入力されます。別の再生経路では
スケール変換したパイロットを除去し、急峻な番組用ローパスフィルターを適用
します。そのため復元音声プレーヤーには RDS の音ではなく番組音声が入り
ます。

RDS にははるかに広いベースバンドが必要なため、安全に使える音響搬送周波数
の範囲が狭くなります。これはスケール変換した教育用波形であり、市販の RDS
受信機では復号できません。

## 複数の FM 放送局

ラジオバンドモードでは、5、12、19 kHz の搬送波を組み合わせます。各局は
±0.75 kHz の周波数偏移と 2 kHz の番組帯域を使います。

```text
5 kHz FM  ─┐
12 kHz FM ─┼─→ 1 つの音響ラジオバンド
19 kHz FM ─┘
```

推定チャンネル幅は約 5.5 kHz で、放送局の間には余裕が残ります。共通
バンドの再生を続けながらライブ受信機が局部発振器を連続的に変えるため、
チューニングはラジオのダイヤルを回すように動作します。

ラジオバンドモードでは RDS を無効にしています。1:8 モデルでは 1 つの
RDS 局が約 17.2 kHz を占有するため、利用可能な 0–24 kHz の音声
スペクトルに複数の忠実な RDS チャンネルは収まりません。

番組が終了するとメッセージはゼロになり、放送局は無変調の搬送波として
継続します。信号レベルのコントロールで各局の強さを変更でき、ミキサーは
3 つの送信機すべてに必要なヘッドルームを確保します。

受信機は複素ベースバンドの急峻なチャンネルフィルターを使用し、スケルチは
適用しません。単独の局は選択チャンネルから外れるにつれて弱くなります。
使用中の 2 チャンネルの間では、両方のスペクトルの一部がフィルターに入る
ため、キャプチャ、干渉、歪んだ音声が聞こえます。ディスクリミネーターは極端な
位相ジャンプを制限し、クリッピングを防ぎます。

## 観察するポイント

- 低い搬送波ほど、変化する笛のような音として聞き取りやすくなります。
- 周波数偏移を大きくすると、エネルギーが搬送波からより遠くまで広がります。
- 搬送波の振幅は一定のまま、振動の速さが変化します。
- RDS は FM 変調前の多重信号に、見える高周波成分を作ります。
- 放送局の間では、自動ミュートではなく、減衰、キャプチャ、干渉を観察できます。

FM は音の下に隠された元音声の小さなコピーではありません。録音を運ぶのは、
累積位相を持つ 1 本の連続した波形です。
