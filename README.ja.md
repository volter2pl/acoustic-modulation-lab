# 音響変調ラボ

**言語：** [English](README.md) | [Polski](README.pl.md) |
[Deutsch](README.de.md) | [Español](README.es.md) |
[Português (Brasil)](README.pt-BR.md) | [简体中文](README.zh-CN.md) | 日本語

**音響変調ラボは、AM・FM ラジオの原理を一般的なブラウザー上で目と耳の
両方から学べるようにします。**

このラボでは電磁搬送波の代わりに、48 kHz の音声波形として保存できる
音響搬送波を変調します。物理的な媒体は異なりますが、AM と FM の数式、
側波帯、チューニング、復調の原理は同じです。

[日本語でラボを開く](https://volter2pl.github.io/acoustic-modulation-lab/?lang=ja)

```text
音声または音楽
      ↓
AM または FM 送信機
      ↓
高周波の音響波形
      ↓
チューニングされた AM または FM 受信機
      ↓
復元された音声または音楽
```

## このラボで学べること

変調方式を選び、同じ録音がそれぞれどのように表現されるか比較できます。

| | AM | FM |
| --- | --- | --- |
| 変化する量 | 搬送波の振幅 | 瞬時周波数 |
| 主なパラメーター | 変調度 | 周波数偏移 |
| スペクトル | 搬送波と 2 つの側波帯 | 搬送波と複数の側波帯 |
| 受信機が測る量 | I/Q 包絡線の大きさ | I/Q 位相変化 |
| 追加実験 | 過変調 | スケール変換した RDS |

アプリケーションは 3 段階の信号を表示します。

1. **メッセージ** — 内蔵録音、独自の音声ファイル、またはマイク入力。
2. **変調信号** — AM または FM の搬送波と側波帯。
3. **復元音声** — 対応する受信機が再構成したメッセージ。

すべての可視化はスペクトログラムです。時間は左から右へ進み、周波数は
下から上へ高くなり、明るい色ほどエネルギーが強いことを示します。
メッセージと復元音声の表示範囲は 0–8 kHz、変調信号は 48 kHz の
サンプルレートで利用できる全範囲 0–24 kHz を表示します。

詳しい理論と実装上の判断については、次の文書を参照してください。

- [振幅変調](docs/ja/am.md)
- [周波数変調と RDS](docs/ja/fm.md)

## 単一局とラジオバンド

**単一局**モードでは、選択した変調方式を特徴づけるパラメーターを操作
できます。AM の変調度は 0% から 150% まで設定でき、意図的な過変調も
試せます。FM では周波数偏移と、スケール変換した PS または RadioText
データを設定できます。

**ラジオバンド**モードでは、5、12、19 kHz の 3 つの独立した放送局を
1 つの音声ファイルに合成します。放送局ごとに異なる番組と信号レベルを
使用できます。共有バンドを再生したまま受信機を連続的にチューニング
できるため、ダイヤルを動かすとリアルタイムで放送局が切り替わります。

復元スペクトログラムとダウンロード可能な WAV は、最後に解析した周波数
で作成したスナップショットです。ライブ音声はチューニングスライダーに
すぐ追従します。スペクトルが古い場合は、**スペクトルと WAV を更新**する
までインターフェースにその状態が表示されます。

番組の長さをそろえる必要はありません。共有チャンネルは最長の録音に
合わせられ、短い AM または FM 番組は終了後も無変調の搬送波として
継続します。

## なぜこれはアナロジーなのか

放送用の搬送波は無線周波数の電磁波として伝わります。この実験では空気圧
の変化と可聴周波数を使うことで、一般的なブラウザーから信号を生成、表示し、
場合によっては再生できるようにしています。

| 無線伝送 | 音響ラボ |
| --- | --- |
| 電磁搬送波 | 音圧搬送波 |
| RF 発振器 | ブラウザーが生成する発振器 |
| アンテナと自由空間 | 音声ファイル、またはスピーカーと空気 |
| ラジオ受信機 | ブラウザーの AM または FM 復調器 |

これは電波を音に変換するものではありません。同じ変調の数学を別の種類の
波に適用したものです。

## 実験してみる

内蔵サンプルを使用するか、音声ファイルをドロップするか、自分の声を録音
してください。ブラウザーでは一般に WAV、MP3、M4A/AAC、OGG/Vorbis、
WebM/Opus が利用できますが、正確な対応形式はブラウザーによって異なり
ます。入力時間は 120 秒までです。

生成された高周波信号は小さな音量で再生され、自動的に再生を始めることは
ありません。機器のスピーカー、マイク、音声補正、フィルターによって、
可聴域上限付近の搬送波が除去される場合があります。

空いている任意のポートでラボをローカル実行するには：

```bash
npm start -- 8080
```

その後、`http://localhost:8080` を開きます。

AM と FM は情報の表現方法を変えます。元の録音を暗号化、圧縮、隠蔽する
ものではありません。
